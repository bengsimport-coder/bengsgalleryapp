Pengaturan Firebase Database Cloud

Hubungkan Blogspot dengan Firebase Firestore Anda

Cara Mengatasi Pesan "Missing or insufficient permissions":

Langkah 1: Buka Firebase Console & select proyek bengsgallery1.
Langkah 2: Buka Firestore Database → Tab Rules.
Langkah 3: Ubah aturan menjadi:

rules_version = '2';
service cloud.firestore {
match /databases/{database}/documents {
match /{document=**} {
allow read, write: if true;
}
}
}

Langkah 4: Klik tombol Publish. Indikator di header akan langsung berubah menjadi 🟢 Terhubung!
